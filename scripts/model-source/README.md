# CC0 anatomy source

Base mesh and adult young macro targets from https://github.com/makehumancommunity/makehuman/tree/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/makehuman/data . Their explicit CC0 notices are preserved in each file. Asset license: LICENSE.CC0.md. MakeHuman program code is not redistributed.

The RRC generator preserves continuous adult anatomy and native UV coordinates; voxel mosaics are removed. Native 2048×2048 skin textures come from the official CC0 asset packs skins01 (Bobby_03, young female hairless) and skins02 (Mindfront, Aksel). The male normal map is reduced to 1024×1024 for runtime; color retains native size. These are textured parametric adult references, not full human photogrammetry scans. Adult reference forms are for nonsexual garment measurement guidance, not scans of members.

Fitted eyes and brown eye texture: MakeHuman data/eyes, copyright holders Data Collection AB, Joel Palmius and Jonas Hauquier; explicitly released CC0 in September 2020 (notice retained in eyes/eyes.mhclo). Native UV texture is preserved. Source: https://github.com/makehumancommunity/makehuman/tree/master/makehuman/data/eyes .

Skin source packs and CC0 declarations: https://static.makehumancommunity.org/assets/assetpacks/skins01.html and https://static.makehumancommunity.org/assets/assetpacks/skins02.html . Original material descriptions are retained in skins/. Downloaded from the official second mirror using ZIP byte ranges and CRC validation. Skin roughness is an authored constant; the specular texture is retained as a source, not relabelled a measured roughness map.
