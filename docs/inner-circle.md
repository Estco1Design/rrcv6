# RRC / Внутренний круг

Название связывает закрытый доступ с сообществом и близостью к ателье. Вход отделён от кабинета: на заставке «Войти на сайт» и «Внутренний круг», во второй ветке вводится код. Локальный код ESTCO; сервер сверяет RRC_PRIVATE_CODES, браузер не хранит допустимые коды. Сессия ограничена семью днями, в базе только хеш токена, выход отзывает его. Аккаунт и private независимы.

Пять рабочих разделов:

- Ранний доступ: будущие изделия, процесс, крупные планы и кадры из цеха. Сейчас подготовлено место для настоящих материалов.
- Private drops: отдельные утверждённые выпуски. Никаких фиктивных таймеров и остатков.
- Предзаказ: настоящий каталог, условия изготовления и переход к изделию; запрос в поддержку отправляет покупатель.
- Привилегии: консультации по посадке, сочетаниям и уходу. Доступность и детали обсуждаются с командой, автоматические скидки и баллы не заявлены.
- Архив: 10 архивных моделей, запрос возможности повторения; это не заявление наличия на складе.

## Как добавить фотографии

Создайте папку `var/private-media/<release-id>/`, например `var/private-media/atelier-jacket/`. Она игнорируется Git и остаётся вне `.next`. Поместите туда фото JPG, PNG, WebP или AVIF (до 16 MiB на файл). Для имён папок и файлов используйте латиницу, цифры, дефис, точку и подчёркивание. HEIC предварительно экспортируйте в один из поддержанных форматов. В `src/config/private-content.ts` добавьте запись в `earlyAccessReleases` или `privateDropReleases`:

```ts
{
 id: 'atelier-jacket',
 title: 'Ваше утверждённое название',
 description: 'Реальное описание и согласованные условия.',
 images: ['/api/private-media/atelier-jacket/front.jpg'],
}
```

После изменения конфигурации пересоберите production. `/api/private-media/…` проверяет сессию, не кеширует ответ публично и не разрешает выход за каталог, в том числе через symlink. Фото не включаются в исходники и не доступны без входа. Для публичной демонстрации можно сознательно использовать фотографии из `public`; это будет открытый доступ к самим файлам.

Постоянный диск должен сохранять `var/private.sqlite`, `var/accounts.sqlite` и `var/private-media`. В `npm run start` пути закреплены вне сборки. В Docker Compose existing account_data volume покрывает каталог var; добавление контента должно происходить в соответствующий volume, а не в новый контейнерный слой.

## Визуальное направление и мобильный UX

Чёрный #070709, графит #262027, молочный #edeae4, винный #651c34 и серебро. Unbounded несёт силуэт бренда, IBM Plex Mono — данные и сервисные элементы. Главный визуальный жест — металлический RRC со складчатой винной лентой; кабинет использует гладкие graphite GLB-скульптуры с линиями мерок. Концепт: `public/images/atelier/fit-concept.png`. Оригинальные модели: `public/models/fit-{male,female}.glb`; регенерация `blender -b --python scripts/generate-fit-models.py` (для обычного запуска Blender не нужен).

Интерфейс ориентирован на быстрые мобильные действия: постоянные пять пунктов навигации, минимум 44px для управления, safe areas, сохранение над нижней навигацией, смена формы и ракурса без ухода со страницы. Круг строится вокруг процесса ателье и диалога, а не искусственных счётчиков внимания. Это дизайнерская гипотеза для аудитории, а не результат исследования всех пользователей поколения Z.

Прямые запросы к Rick Owens, Acne Studios и SSENSE были заблокированы сетевой политикой (proxy 403). Их live интерфейсы не исследованы и не используются как доказательство. Применены доступные рекомендации Vercel Web Interface Guidelines, Motion, Three.js и установленные навыки дизайна. Remotion установлен как навык для будущих видео; интерактивная заставка выполняется Three.js, видео-runtime в сайт не добавлен.
