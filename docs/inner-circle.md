# RRC / PRIVATE ACCESS

Вход расположен только на первой заставке: «ВОЙТИ» открывает публичный сайт, «PRIVATE ACCESS» — форму кода. ESTCO проверяется сервером через RRC_PRIVATE_CODES. После проверки показывается архитектурная анимация и «Поздравляем. Ты внутри.», затем переход в закрытые разделы. Обычный вход скрывает private-навигацию и отзывает старую private-сессию. Регистрация кабинета не открывает private. Подсказка sessionStorage управляет только видимостью; страницы и файлы всегда проверяют серверную сессию.

Сессия имеет случайный HttpOnly токен, в SQLite хранится его хеш. Срок — семь дней; выход отзывает токен. Аккаунт и PRIVATE ACCESS независимы.

Пять разделов: ранний доступ, private drops, предзаказ, привилегии, архив. Предзаказ и архив используют настоящий каталог. Закрытые изделия добавляются позже через src/config/private-content.ts. Подарки, инсайды, непубличные дизайны, обсуждения, персональные советы и приглашения на показы описаны на главной private-странице. Будущие подарки и события ожидают анонса; интерфейс не обещает скидок или наличия.

Поддержку открывает сам покупатель через Telegram. Закрытые фотографии хранить в var/private-media, пути задавать как /api/private-media/имя-файла.jpg. Этот API проверяет авторизацию, тип файла и выход за пределы каталога. Файлы в public всегда доступны публично.

Сохранять var/private.sqlite, var/accounts.sqlite и var/private-media на постоянном диске. npm start закрепляет пути вне .next.

## Дизайн

Чёрный фон, существующие шрифты и фотографии RRC, свободные поля. Начальная заставка — только название и два входа, без скульптуры, слоганов и года. Продуктовая карточка показывает категорию, название и цену. Мобильная навигация раскрывается нажатием или свайпом вверх за абстрактный язычок; закрывается повторным нажатием, свайпом вниз или переходом. PRIVATE ACCESS появляется только после соответствующего входа.

## 3D для мерок

Анатомическая сетка взрослых мужской и женской форм основана на CC0-данных MakeHuman. Происхождение и лицензия: scripts/model-source/README.md и LICENSE.CC0.md. Это иллюстративный ориентир, не скан человека и не реконструкция тела пользователя по меркам. Текстур сканирования нет; используется матовый материал с цветом вершин.

GLB: public/models/fit-{male,female}.glb. Белая сцена, вращение, масштабирование, контурные мерки и подписи. Лицо, грудь и таз закрыты непрозрачными объёмными пикселями, закреплёнными на геометрии. Поверхности под масками удалены из экспортированных моделей. Статические fallback-изображения отрисованы из тех же закрытых моделей. Регенерация: blender -b --python scripts/generate-fit-models.py; Blender для запуска сайта не требуется.

Движение интерфейса короткое и спокойное; prefers-reduced-motion отключает переходы. Обзор чужих live-сайтов и измерения production Core Web Vitals в этой версии не проводились.
