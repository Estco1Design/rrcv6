# Входная сцена и взрослые 3D-ориентиры

## Текущий визуальный результат

Последнее уточнение пользователя меняет ориентир ткани: необходимо сохранить конкретный рисунок последнего мобильного скриншота. В проекте найдены соответствующие оригинальные арты без текста. Активная сцена теперь использует их на двух отдельных деформируемых сетках. PBR-эксперименты, менявшие вид складок, выключены из runtime. [Техническое описание и ограничения метода](reference-cloth-restoration.md).

- [Запись хореографии](media/reference-cloth/intro-visual.mp4): 112 фактических кадров production-браузера с управляемыми часами, 24 кадра/с. **Не измерение FPS.**
- [Вступление с обычными часами](media/reference-cloth/intro-native.mp4), [захваты мышью](media/reference-cloth/grab-desktop.mp4), [захваты пальцем в эмуляции](media/reference-cloth/grab-mobile.mp4).

Надпись — настоящий HTML. Для заголовка входа подобран Helvetica Neue / Arial / sans-serif: 530 px ширины при 1280 px и 231 px при 390 px. Это подбор под растровый образец, а не утверждение о восстановлении неизвестного оригинального файла шрифта. Глобальные Unbounded и IBM Plex Mono сайта сохранены.

## Личный кабинет

Подключены взрослые модели MakeHuman с нативной топологией кистей, стоп, груди, таза и суставов. Стандартный скелет имеет 163 кости, веса взяты из CC0 MPFB. Руки опущены через взвешенную суставную позу, с небольшим сгибом локтей; отдельно подготовленная полная форма оставляет дополнительный зазор около тела.

Lean/Full — настоящие native macro-targets minweight/maxweight, вычисленные через тот же риг; это не масштабирование модели по трём осям. Диапазон UI ограничен ±0,55. Четыре основных контура мерок следуют морфам. Форма не выводится из введённых личных данных, не является цифровым двойником и не проверяет посадку одежды.

Три причёски short01 / bob01 / ponytail01 — скачанные CC0 hair cards с исходными UV и RGBA-текстурами. Barycentric fitting выполнен отдельно для каждой головы. Runtime использует alpha test / alpha-to-coverage, без сортируемых прозрачных оболочек. Это не strand-groom и не фотограмметрия.

- Мужская модель: [спереди](media/final-quality/male-front.png), [сбоку](media/final-quality/male-side.png), [сзади](media/final-quality/male-back.png), [Lean](media/final-quality/male-lean.png), [Full](media/final-quality/male-full.png).
- Женская: [спереди](media/final-quality/female-front.png), [сбоку](media/final-quality/female-side.png), [сзади](media/final-quality/female-back.png), [Lean](media/final-quality/female-lean.png), [Full](media/final-quality/female-full.png).
- Волосы: [короткие](media/final-quality/female-hair-short01.png), [каре](media/final-quality/female-hair-bob01.png), [собранные](media/final-quality/female-hair-ponytail01.png).
- [Взаимодействие с моделями](media/final-quality/anatomy-interaction.mp4), [подробные результаты](media/final-quality/anatomy-acceptance.json).

GLB сжаты Meshopt без упрощения анатомической поверхности: male 7 904 124 → 3 729 908 байт, female 6 634 044 → 2 378 744. Одна выбранная причёска — примерно 1,04–1,43 MB. Загружается только выбранная модель/причёска. Импорт 3D отложен до появления блока вблизи viewport, до авторизации модели не запрашиваются. Новые готовые fallback-изображения показывают ту же расслабленную позу и волосы на прозрачном фоне поверх белой панели.

Старт кабинета исправлен отдельно: статус ready выставляется после загрузки выбранных волос, компиляции и первого кадра. Убрана повторная загрузка начальной причёски. При смене волос предыдущая причёска сохраняется до готовности следующей. Затухание OrbitControls привязано к прошедшему времени, чтобы низкая частота кадров не растягивала инерцию. Фиксированные виды очищают остаточное вращение. Скрытая вкладка и покой не поддерживают непрерывный RAF; уход со страницы освобождает геометрию, текстуры, контроллеры, observers и WebGL-контекст.

## Измерения вступления

Chromium 154 / SwiftShader, Linux Xeon Platinum 8573C, cgroup 4 CPU. Новый браузер, пустой HTTP-кеш, production-сервер уже запущен; 390×844, DPR устройства 3, canvas 576×1248, MSAA 4, без видеозаписи и других рендеров. Это один прогон на условие, не проверка реального телефона.

| Условия | Подготовка после импорта сцены | Первый показ от начала навигации | Вызов render p50 / p95 | Интервал отправки render p50 / p95 |
| --- | --- | --- | --- | --- |
| localhost | 934,9 мс | 4056,9 мс | 2,2 / 7,6 мс | 93,7 / 181,6 мс |
| CPU ×4, 8 Mbps, RTT 80 мс | 4481,2 мс | 8402,6 мс | 12,5 / 42,8 мс | 110,5 / 298,5 мс |

[Полный JSON фаз загрузки](media/reference-cloth/cloth-cold-start.json) отдельно фиксирует fetch, bitmap decode, разбор GLB, завершение GPU upload, compile и warmup. Интервалы сняты с обновлений render-count, это не аппаратные GPU timestamp и не точное время показа кадра дисплеем. Цель 30 кадров/с в SwiftShader не достигнута; плавность на настоящем телефоне **не подтверждена**. Разрешение и детали не объявляются причиной качества сами по себе.

В одном параллельном прогоне landscape ожидание complete завершилось таймаутом. Повтор без конкурирующих WebGL/Blender-прогонов прошёл. Причина первого таймаута полностью не изолирована; её нельзя выдавать за исправленный мобильный FPS. Остальные сценарии и итог отдельных повторов перечислены в результатах проверок.

## Проверки

`npm run check`: ESLint с нулём предупреждений, TypeScript, **32 unit-теста**, production build. Браузерные сценарии проверяют оба полотнища, release outside, pointercancel/lost capture, дополнительное касание, resize/hidden, idle stop, повтор и пропуск, рабочие публичный/приватный входы, reduced motion, повреждённые фото/GLB/HDR и bounded timeout. В кабинете проверены обе формы, три причёски, front/side/back, крайние морфы, touch orbit, неизменность личных мерок при морфах, сохранение и удаление тестового аккаунта, уход со страницы и fallback.

Прежний dev-индикатор «1 Issue» в исходном виде не воспроизвёлся. В dev-журнале обнаружено реальное предупреждение Next/Image: quality 72 отсутствовало в images.qualities. Конфигурация приведена к используемым 72/75/100. Индикатор N не отключался и ошибки консоли не подавлялись.

Ограничения: свет ткани запечён в утверждённом арте и не может независимо пересчитываться как у настоящего PBR-материала; режущий контакт остаётся постановочной realtime-анимацией; ножницы — авторская CAD-модель, не скан инструмента. Для следующего уровня нужны профессиональный лицензированный скан/CAD округлых закройных ножниц и калиброванный тканевый scan/render pipeline, если потребуется свободное физическое переосвещение при точном совпадении с образцом. Фигуры — параметрические взрослые ориентиры, не фотографические копии людей. Полного фотографического совпадения всех объектов и «гиперреализма» не заявляем.

Опубликованный сайт и main не обновлялись. Проверять локально: Node 24 LTS, `npm ci`, `npm run build`, `npm start`; для повторного вступления — новая приватная вкладка. Для запуска не нужны Blender или Python: подготовленные GLB, изображения и метаданные уже находятся в проекте.
