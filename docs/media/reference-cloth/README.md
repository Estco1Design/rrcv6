# Доказательства текущего вида

PNG — кадры production-браузера, не макеты. `mobile-reference.png` имеет пропорции области сайта на последнем скриншоте пользователя; браузерная панель iOS не является частью сайта и не дорисовывается.

`appearance.json` сравнивает два участка ткани с масштабированными исходными утверждёнными изображениями и фиксирует реальный CSS-шрифт. Средняя абсолютная ошибка RGB выражена в шкале 0–255. Это проверка сохранения рисунка, а не физического реализма освещения.

Видео с управляемыми часами служит проверкой хореографии; нативные записи интерактивности помечены отдельно. Они не свидетельствуют о FPS на настоящем телефоне. Все мобильные кадры сняты в Chromium-эмуляции.
