# RICHRUSSIANCOMMUNITY

Исправленная версия сайта RRC. Шрифты Unbounded и IBM Plex Mono, палитра, фотографии и основные композиции сохранены.

## Запуск

Нужен Node.js 24 LTS: встроенный SQLite используется для личных кабинетов.

```bash
npm ci
npm run dev
```

Для проверки с телефона в одной Wi-Fi сети:

```bash
npm run dev:lan
```

Откройте на телефоне адрес, который напечатает команда. Телефон и компьютер должны быть в одной сети.

## Контакт для заявок

Подтверждённый контакт для заказов — @rrc_support. Он задан по умолчанию, канал @richrussiancommunity размещён отдельно. Для переопределения перед сборкой укажите в `.env.local`:

```env
NEXT_PUBLIC_RRC_TELEGRAM=rrc_support
```

Можно также указать реальную рабочую почту, ссылку VK и адрес опубликованного сайта:

```env
NEXT_PUBLIC_RRC_EMAIL=
NEXT_PUBLIC_RRC_VK=
NEXT_PUBLIC_SITE_URL=
```

Переменные `NEXT_PUBLIC_*` попадают в сайт при сборке. После их изменения нужно пересобрать сайт. На хостинге задайте их в настройках окружения до сборки.

Для Telegram нужен аккаунт, в который покупатель может написать сообщение. Обычный канал без открытой переписки не подходит.

## Как работает запрос

1. Покупатель выбирает изделие, цвет и доступный размер.
2. В корзине отмечает нужные позиции.
3. На странице запроса указывает предпочтение доставки, при желании имя, город, индекс, ПВЗ/адрес и комментарий, затем готовит сообщение.
4. Копирует текст или открывает Telegram с подготовленным сообщением.
5. Сам отправляет сообщение. Бренд подтверждает цену, наличие, посадку и срок изготовления перед оплатой.

Сайт не принимает платежи, не присваивает фиктивный номер заказа и не выдаёт подготовку сообщения за отправку. Корзина сохраняется. Если контакт не настроен, интерфейс честно сообщает, что приём заявок ещё не открыт.

## Каталог

Единый источник — `src/lib/products.ts`. В каталоге 15 моделей с утверждёнными ценами, все — PRE-ORDER. Несуществующая модель №10 удалена. CURRENT содержит №1, 4, 5, 11, 15; остальные 10 моделей в архиве. Цены и номера — в PRICES.md.
Для каждого изделия заполните реальные `price`, `sizes`, `materials`, `inStock`; для предзаказа задайте `preorder: true`. `salePrice` — сниженная цена, `price` — обычная.

Неуказанная цена остаётся `null`. Она не считается нулевой; доставка и итог для такого запроса подтверждаются в переписке. Размеры 1/2/3 заданы владельцем как обозначения для запроса; точные мерки изделия ещё нужно предоставить. Чёрная футболка с боковыми молниями пока без фотографий: показана заглушка с подписью. Зипка с координатами полностью удалена. Не подставляйте снимки других изделий.

Имена файлов для этих фотографий:

- `public/products/side-zip-tee-black-front.jpg` и остальные ракурсы `back`, `detail`, `model`.

После добавления файлов включите `views("side-zip-tee-black")` вместо пустых массивов `images` у соответствующих цветов.

Доставка оплачивается по тарифу перевозчика. До подключения API стоимость и полный итог подтверждаются в переписке; фиксированные 500 ₽ и бесплатный порог больше не применяются. Адрес отправления хранится в src/config/site.ts, необходимые данные перечислены в SHIPPING.md.

## Закрытая зона

При локальном запуске `npm run dev` или `npm run dev:lan` автоматически создаётся `.env.local` со случайным секретом и кодом `estco`, если эти значения ещё не настроены. Уже заданные коды сохраняются. Чтобы настроить отдельно: `npm run setup:local`. После изменения `.env.local` перезапустите сервер.

Код для первого локального входа: `estco`. Это серверный код, он не встроен в браузер. Для опубликованного сайта задайте свои значения на хостинге; локальная настройка туда автоматически не переносится. Без серверных настроек опубликованный private-доступ закрыт.

Сгенерируйте секрет:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

Задайте на сервере `RRC_PRIVATE_SESSION_SECRET` и свои коды в `RRC_PRIVATE_CODES`, разделённые запятыми. Секрет должен содержать минимум 32 символа. Эти параметры не должны иметь префикса `NEXT_PUBLIC_`.

Сессия подписана, действует 7 дней, хранится в HttpOnly-cookie; при выходе удаляется. Сервер и middleware проверяют подпись и срок действия. Cookie со значением `1` доступ не даёт.

Ограничение попыток ввода кода работает в пределах процесса. При размещении на нескольких инстансах дополнительно настройте общий лимит запросов на хостинге. В private-зоне сохранены будущие разделы, но они показаны как ещё не открытые, без фиктивных переходов. Заглушка админского входа убрана.

## Проверка и публикация

```bash
npm run check
npm run start
```

`check` запускает линтер без предупреждений, проверку TypeScript, регрессионные тесты и production-сборку. Разворачивайте именно production-сборку. Не публикуйте `.env.local`, `node_modules` и `.next` как исходники.

Страницы конфиденциальности и доставки описывают текущий ручной сценарий. Перед подключением оплаты, базы заказов или аналитики потребуется обновить эти страницы и добавить реальные сведения о продавце и его условиях.

Изменения и результаты проверки описаны в `CHANGES.md`.

## Контакты, размеры и доставка — v5

Заказы и поддержка: @rrc_support; канал: @richrussiancommunity. Размеры запроса: 1/2/3 с ориентиром S/M, M/L, L/XL. Ранее заданный ONE SIZE сохранён у одной модели; точных мерок ещё нет. Пожелание свободнее хранится отдельно от размера и сохраняется при перезагрузке корзины.

Предзаказ — 100% предоплата, изготовление до 14 рабочих дней: дата оплаты в будни — день 1, в выходные старт в понедельник. Для праздников нужен график производства.

Доставка теперь по тарифу перевозчика: 500 ₽ и бесплатный порог убраны. Цена доставки и полный итог пока подтверждаются вручную до оплаты. Не объявляйте API-расчёт, платежи или отслеживание работающими до подключения. SHIPPING.md и ORDER_FLOW.md описывают данные и этапы запуска.

## Личные кабинеты (v6)

/account — отдельная регистрация и вход по логину/паролю, профиль и паспорт посадки. Данные хранятся в SQLite на сервере; пароли и коды восстановления — только в виде хешей. После регистрации сохраните выданный код восстановления. /studio/clients — внутренняя страница команды с отдельным серверным токеном и только разрешёнными клиентами профилями. Подробнее: ACCOUNTS.md.

Локальная настройка включает регистрацию, если значение ещё не задано. Production-шаблон оставляет её закрытой до подготовки сервера и сведений оператора. Публичная регистрация включается RRC_ACCOUNT_SIGNUPS=1 на сервере. Почта для связи не является способом входа или восстановления.

Создание support@richrussiancommunity.com: MAIL_SETUP.md. Примерные параметры упаковки и ориентиры размеров: SHIPPING.md и src/config/body-size-guide.ts. Упаковка не используется для выставления тарифа, таблица тела не заменяет измерения изделий.
