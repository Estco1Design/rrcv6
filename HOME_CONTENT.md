# RICHRUSSIANCOMMUNITY — Campaign Content Guide

## Где добавлять изображения

Все изображения для главной страницы хранятся в папке:

```
public/images/campaigns/
```

### Требования к изображениям

- **Формат:** JPG или PNG
- **Рекомендуемый размер для desktop:** 1920x1080 px или больше
- **Рекомендуемый размер для mobile:** 750x1334 px (можно использовать одно изображение для обоих режимов)
- **Качество:** Сжатие без видимых артефактов, до 500 KB желательно

## Как добавить новый слайд в карусель

1. Положите файл изображения в `public/images/campaigns/`, например `slide-2.jpg`

2. Откройте `src/config/home-content.ts`

3. Найдите массив `heroSlides` и добавьте новый объект:

```typescript
{
  id: 'slide-2',
  desktopImage: '/images/campaigns/slide-2.jpg',
  mobileImage: '/images/campaigns/slide-2.jpg',
  desktopObjectPosition: 'center 40%',
  mobileObjectPosition: 'center 35%',
  altRu: 'Описание на русском',
  altEn: 'Description in English',
  captionRu: 'ОСЕНЬ — ЗИМА 2026',
  captionEn: 'FALL / WINTER 2026',
  linkHref: '/shop',
}
```

4. Сохраните файл — карусель обновится автоматически при разработке

## Как удалить или скрыть слайд

- Удалите соответствующий объект из массива `heroSlides`
- Или закомментируйте его, добавив `//` перед фигурной скобкой

## Как изменить порядок слайдов

Измените порядок объектов в массиве `heroSlides` в файле `src/config/home-content.ts`. Первый элемент — первый показываемый слайд.

## Настройка кадрирования для мобильных

Параметр `mobileObjectPosition` управляет фокусной точкой изображения на мобильных устройствах:

- `'center center'` — центр
- `'center 40%'` — смещение вверх (40% от верха)
- `'center 60%'` — смещение вниз
- `'50% center'` — смещение по горизонтали

Подбирайте значение так, чтобы важная часть композиции (лицо модели, логотип) оставалась видимой.

## Как заменить нижнее редакционное изображение

1. Положите новое изображение в `public/images/campaigns/`, например `editorial-new.jpg`

2. В `src/config/home-content.ts` найдите объект `editorial.mirrorScene`

3. Измените свойство `desktopImage`:

```typescript
editorial: {
  mirrorScene: {
    id: 'editorial-mirror',
    desktopImage: '/images/campaigns/editorial-new.jpg',
  }
}
```

## Когда требуется пересборка

- **При локальной разработке (`npm run dev`)**: изменения применяются мгновенно, перезапуск не нужен
- **Для продакшена**: после изменений выполните `npm run build` перед деплоем
- **Если изменились только тексты/ссылки**: достаточно сохранить файл

## Важно

Просто положить изображение в папку `public/images/campaigns/` **недостаточно**. Необходимо обязательно добавить запись в конфигурацию `src/config/home-content.ts`, иначе изображение не появится на сайте.

## Структура конфигурации

```typescript
HOME_CONTENT = {
  heroSlides: [ /* массив слайдов */ ],
  editorial: {
    mirrorScene: { /* нижнее изображение */ }
  }
}
```

Каждый слайд должен иметь уникальный `id`.
