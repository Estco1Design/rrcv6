# Доступ к сайту с телефона по локальной сети

## Запуск сервера для доступа с телефона

1. **Убедитесь, что компьютер и телефон подключены к одной Wi-Fi сети**

2. **Запустите сервер командой:**
   ```bash
   npm run dev:lan
   ```

3. **Скрипт автоматически определит ваш локальный IP-адрес** и покажет его в терминале:
   ```
   ========================================
     RRC DEV SERVER - LAN ACCESS
   ========================================

     Local IP: 192.168.1.XXX
     URL:      http://192.168.1.XXX:3000

     Откройте этот адрес на телефоне.
     Убедитесь, что телефон и компьютер в одной Wi-Fi сети.

   ========================================
   ```

4. **Откройте браузер на телефоне** и введите адрес вида:
   ```
   http://192.168.1.XXX:3000
   ```
   (где XXX — номер, который покажет скрипт)

---

## Если не удаётся подключиться

### 1. Проверьте брандмауэр Windows/macOS
- Разрешите входящие подключения для Node.js
- Не отключайте брандмауэр полностью — достаточно добавить правило для Node

### 2. Проверьте изоляцию устройств в роутере
- Некоторые роутеры имеют настройку «AP Isolation» или «Client Isolation»
- Эта настройка запрещает устройствам видеть друг друга
- Отключите её в настройках роутера

### 3. Убедитесь, что компьютер не спит
- В режиме сна сетевые адаптеры могут отключаться

### 4. Попробуйте другой порт (если 3000 занят)
Если порт 3000 занят, измените команду в `package.json`:
```json
"dev:lan": "node scripts/get-local-ip.js && next dev --hostname 0.0.0.0 --port 3001"
```

---

## Важно

- **Не используйте `localhost` или `127.0.0.1`** — эти адреса работают только на самом компьютере
- **Не используйте `0.0.0.0`** — это специальный адрес для прослушивания всех интерфейсов, а не реальный IP
- Адрес должен быть вида `http://192.168.x.x:3000` или `http://10.x.x.x:3000`
- Подключение работает только по **HTTP**, не по HTTPS

---

## Для разработчика

Скрипт определения IP находится в `scripts/get-local-ip.js`.
Команда запуска добавлена в `package.json` как `dev:lan`.
